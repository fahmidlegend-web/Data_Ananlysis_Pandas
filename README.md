### Hospital Data Analysis
A prediction based Hospital report analysis based on factors such as Age,Diagnosis,BloodPressure,Heart Rate and Temperature
By this we can understand if a patient is going to die or not, 

if outcome = 0.0- the patient is safe
if outcome = 0.4- the patient is moderately safe
if outcome = 0.7- the patient is at moderate risk 
if outcome = 1.0 - the patient is at high risk
